# Weekly Objectives

The objective of this week was to move from simply understanding algorithms to designing a complete experimental framework for comparing different approaches to the Truck-Drone Vehicle Routing Problem with Time Windows (Truck-Drone VRPTW).

Instead of only making existing code run, I focused on understanding the principles behind several representative algorithms, their implementations, and how to fairly compare them under the same experimental settings.

# Work Completed

## 1. Literature Review and Algorithm Learning

During this week, I studied several representative algorithms related to vehicle routing optimization.

The main algorithms include:

- **POMO (Policy Optimization with Multiple Optima)** based on reinforcement learning.
- **Genetic Algorithm (GA)** and its evolutionary optimization process.
- **PyVRP**, including its solver framework and optimization workflow.
- **Google OR-Tools**, focusing on routing models, constraints, and search strategies.

The learning process mainly focused on understanding:

- algorithm principles;
- optimization strategies;
- route representation;
- objective functions;
- constraint handling;
- project structures of the open-source repositories.

Rather than only executing the code, I attempted to understand how each framework is organized and how the optimization process is implemented.

## 3. Experimental Design

Based on the Week 3 requirements, I designed the overall experimental framework.

The current comparison plan is:

- **Baseline:** OR-Tools (Truck-only)
- **Method 1:** OR-Tools (Truck-Drone)
- **Method 2:** Genetic Algorithm (GA)
- **Method 3:** IVND algorithm from the selected Truck-Drone paper

The experiments will use:

- the same R101 dataset;
- identical customer subsets (20, 50, and 100 customers);
- the same objective function;
- identical stopping conditions whenever possible.

The main research questions are:

1. Does the Truck-Drone setting reduce the total delivery cost compared with Truck-only routing?

2. Under the same instances, which algorithm achieves better objective values and computational efficiency?

These questions will guide the implementation and experimental evaluation in the following stage.
